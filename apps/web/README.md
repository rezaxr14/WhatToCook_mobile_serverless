# @whattocook/web

Serverless web client: React + Vite, deployed as static files to Vercel, Fastly or GitHub Pages.
Talks directly to Supabase (PostgREST/RLS, RPC, Edge Functions). No server runtime.

```bash
pnpm --filter @whattocook/web dev
pnpm --filter @whattocook/web build
pnpm --filter @whattocook/web test
```

Status: M0 placeholder. Real screens land in WM1–WM3 (see `implementation_plan.md`, local-only).
